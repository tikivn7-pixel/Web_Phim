Quản lý phim

Chỉnh sửa và xem trước trên trình duyệt. Bản nháp chỉ nằm trên thiết bị này; website chỉ đổi sau khi bạn xuất và cập nhật dữ liệu.

Đang tải kho phim...

Cách cập nhật website
  1. Lưu các thay đổi vào bản nháp rồi bấm Xuất JSON để cập nhật.
  2. Tại thư mục dự án, chạy npm run catalog:import -- "đường-dẫn/catalog-import.json". Lệnh giữ bản sao nguồn cũ và xuất các file dữ liệu mới.
  3. Đăng lại thư mục Frontend/data và những ảnh mới lên hosting. Không cần bật backend khi xem.
